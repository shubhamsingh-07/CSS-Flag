# CSS Flag Project — Laos

[![HTML5](https://img.shields.io/badge/HTML5-markup-orange.svg)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-layout-blue.svg)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A static recreation of the flag of Laos using only HTML and CSS. The flag is assembled from nested `div` elements, positioned blocks, solid colors, and a circular white emblem.

## Project Files

- `index.html` — the main implementation, with CSS embedded in the document.
- `solution.html` — an alternate/reference implementation.
- `goal.png` — a visual reference image.

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in a modern browser.
3. Open `solution.html` separately to compare the CSS approaches.

No dependencies, JavaScript, or build tools are required.

## Concepts Practiced

- CSS selectors and nested element targeting.
- Relative and absolute positioning.
- Sizing, colors, and circular shapes with `border-radius`.
- Building a graphic from HTML elements rather than an image.

## Known Limitations

- The flag uses fixed dimensions of 900 × 600 pixels, so it is not responsive to smaller screens.
- The CSS is embedded in each HTML file, which creates duplicated styles.
- The page is a visual exercise and does not include a responsive or accessible alternate description of the flag.
